# FastBox Logistics Simulator

Logistics routing simulator developed for the Nexgensis Technologies Python assignment.

## Overview
This project simulates one day of operations for FastBox, mapping packages from warehouses to destinations using the nearest available delivery agents. It dynamically assigns routes based on proximity, tracks total distance traveled, and evaluates agent efficiency.

## Execution
No external dependencies are required. The system utilizes standard Python libraries (`json`, `math`, `csv`).
1. Ensure the input file `data.json` is in the same directory as the script.
2. Run the simulation from your terminal:
   ```bash
   python simulator.py
